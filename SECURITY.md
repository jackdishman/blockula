# Security

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/jackdishman/blockula/security/advisories/new), not in a public issue or PR.

In scope: the node (consensus, state transitions, the tx encoding, p2p, the HTTP API), the SDK and passkey wallet, the MCP server, and the contribution machinery (GitHub links, claims, Séances, payouts). Include a deterministic repro if you can.

Blockula has had an internal review but no third-party audit yet (see the README).
