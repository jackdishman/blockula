# Fonts

The renderer draws with these files and no others (it loads no system fonts), so a picture comes out the same on every machine. They are the faces the Blockula site uses.

| File | Family (as the file names it) | Version | Copyright line in the file |
|---|---|---|---|

| `EBGaramond-Regular.ttf` | EB Garamond | 1.003 | Copyright 2017 The EB Garamond Project Authors (https://github.com/octaviopardo/EBGaramond12) |
| `IMFellEnglish-Regular.ttf` | IM FELL English | 3.00 | © 2007 Igino Marini (www.iginomarini.com) With Reserved Font Name IM FELL English Roman |
| `IMFellEnglishSC.ttf` | IM FELL English SC | 3.00 | © 2007 Igino Marini (www.iginomarini.com) With Reserved Font Name IM FELL English SC |
| `CourierPrime-Regular.ttf` | Courier Prime | 3.018 | Copyright 2015 The Courier Prime Project Authors (https://github.com/quoteunquoteapps/CourierPrime). |

The copyright lines are copied from each file's own `name` table (record 0). The files are unmodified.

## License

All five are distributed under the **SIL Open Font License, Version 1.1**. Each file's `name` table says so: its license URL (record 14) is `http://scripts.sil.org/OFL` (`https://openfontlicense.org` in EB Garamond), and UnifrakturMaguntia's copyright record adds "This Font Software is licensed under the SIL Open Font License, Version 1.1."

The license's full text is in `OFL.txt` beside this file, as published at <https://openfontlicense.org/documents/OFL.txt> (its header is the license's own template; the copyright lines that apply are the ones tabulated above). One copy covers all five fonts.

Under the license the Reserved Font Names above can't be used for modified versions of the fonts. These files aren't modified, and the pictures made with them aren't covered by the license.
